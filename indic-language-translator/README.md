# 🌐 Indic Language Translator

Translate across Indian and global languages with an agent-friendly workflow designed for practical multilingual use.

---

## What this skill is for

A lot of translation tools are built for global enterprise workflows and feel awkward for actual Indian-language operations.

This skill is for:
- Hindi
- Marathi
- Tamil
- Telugu
- Bengali
- Kannada
- Malayalam
- Gujarati
- Punjabi
- and other multilingual workflows where speed and usability matter

## Best use cases

- founder/customer communication
- multilingual WhatsApp workflows
- translating short-form operational text
- adapting prompts, notes, or responses across languages

## What makes it useful

- built for agent workflows, not just human copy-paste
- lightweight enough for day-to-day translation tasks
- usable from CLI or automation flows
- good fit for Indian-language distribution contexts

## Why this matters

Translation is not a side feature in India.
It is infrastructure.

If your stack speaks only English, it is artificially smaller than it should be.

## Limitations

- output quality depends on source clarity and provider quality
- may need human review for sensitive or public-facing copy
